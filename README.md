## ✨ Overview

This portfolio replaces a traditional static layout with an **interactive 3D developer journey**.

Scrolling moves the camera through different sections:

**🏠 Home → 👨‍💻 About → 🎓 Education → ⚙️ Skills → 💻 Projects → 📡 Contact**

The 3D environment provides the visual experience while the portfolio content remains **HTML-based, responsive, and accessible**.
